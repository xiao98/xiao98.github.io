Research

Interests

I am interested in generative modeling, in particular flow matching and diffusion language models, and in the numerical side of it: ODE solvers for sampling and optimal transport on GPUs.

I also build LLM agents for tasks where correctness can be verified without an LLM in the loop, such as engineering simulation and formal proof.

Software

  • SmokeAgent — LLM agent for fire-safety simulation Turns a French brief into a validated NIST FDS study. The LLM fills a typed scenario spec, a deterministic writer emits the input file, and repairs are JSON patches on the spec. On FireBench, built from NIST's own FDS validation suite, the agent reproduces FDS within the validation guide's uncertainty on 10/10 basic cases with no human edits. code
  • OpenGOAL — long-horizon multi-agent orchestration A goal plus machine-checkable success criteria drives a persistent loop of role-based sub-agents (coder, tester, reviewer, debugger) that iterates until the criteria pass, with one git commit per iteration and budget guards. code
  • tinylm — the full LLM lifecycle from scratch Data, BPE tokenizer, GPT pre-training, SFT/DPO, int4/int8 quantization, evaluation with a contamination check, and sampling. Config-driven, CI-tested, runs on a laptop CPU. code
  • presidio-fr — on-device masking of French personal data before it reaches an LLM Checksum-validated rules (NIR, SIREN/SIRET, IBAN) combined with a ModernBERT NER, shipped as a browser extension and as a local gateway that restores placeholders in streamed replies. Evaluated on FR-PII-Bench (300 documents, 2,105 entities): recall 0.990 at precision 0.973. docsdataset
  • Pylean4 — Lean 4 kernel reimplemented in Python Dependent type checker (weak-head normal form, definitional equality, inductive types) with a minimal tactic framework and REPL. code
  • mini-cc — coding agent from scratch Tool-calling agent loop in TypeScript with streaming, an approval gate before side effects, and persistent sessions. code
