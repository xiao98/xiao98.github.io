Concept-guided exploration under limited compute

Rewards for training a small model to guide a larger one

A small-scale reproduction of Labiad et al. (2026), where a small concept generator, trained with RL, lists approaches that a larger frozen model then follows. On one GPU, untrained concepts improve pass@8 by about 5 points over repeated sampling, but training left the reward flat: re-scoring the same lists shows the reward signal is too noisy at this budget.

Sequential Gaia2 memory ablation

What carried memory does for a personal-assistant agent

An ablation on Meta's Sequential Gaia2 benchmark that splits an agent's carried memory into the conversation and the files it writes. Memory does not change accuracy, but it cuts app calls late in a chain from 19 to 5 per task, and the whole saving comes from the files.

Ask-or-act decisions on Gaia2

Whether an agent asks before acting on an ambiguous request

An experiment on the ambiguity split of Meta's Gaia2 benchmark with the model and harness fixed. Rewriting one rule of the agent instructions so that it lists common ambiguity patterns cut case-verified premature state-changing actions from 15 to 5 and raised passes from 9 to 19 on 30 held-out scenarios (exact McNemar test, Holm-corrected p = 0.006). On a random subset, execution tasks were unaffected (32/40 vs 33/40).

mini-conductor

Does an orchestrator use a worker it has never seen?

A single-GPU re-implementation of the orchestration setup of Sakana AI's Conductor (ICLR 2026), with workers shown by name and description instead of ordinal IDs. After the supervised warm start, a much stronger unseen worker appears in the top-level plan of only 8 of 150 episodes; seen workers are found wherever their ID is shuffled, while the unseen one is picked mainly when it lands on an ID used in training. These are results before RL: the GRPO stage has not been run to completion.

DiffusionGemma stage 1 at 135M scale

Converting a causal language model into a diffusion model on one GPU

A PyTorch port of the supervised stage and entropy-bounded block sampler of DiffusionGemma, written from the official JAX code and applied to a 135M causal language model. It reproduces the paper's trend for the supervised checkpoint (sample perplexity 57 to 32 as denoising steps go from 48 to 192) and documents where the small model differs: about one committed token per step, against about 4.5 in the paper.

Collaborative RSA on MDDial

When pragmatic reasoning over an LLM reduces to a uniform speaker

A reproduction and analysis of the MDDial experiment in Collaborative Rational Speech Act (EMNLP 2025), from the released outputs and a standalone implementation of the model equations. In this setting the CRSA speaker is uniform, which accounts for the reported dialog perplexity (15.362 = √(2·118)); a normalisation fix brings the RSA baseline to the same value (15.395 to 15.362). The reference-game conclusions of the paper are unchanged.

triton-trace-rl

In progress · A multi-turn RL environment for GPU kernel optimisation

KernelBench (levels 1–2) restricted to Triton, packaged as a verifiers environment: the agent rewrites a PyTorch reference as Triton kernels, receives compile, correctness, timing and profiler feedback, and resubmits. The environment, sandbox and anti-reward-hacking guards are written and tested; no evaluation or training numbers exist yet.
