OpenGOAL

Persistent multi-agent problem solving

OpenGOAL is a multi-agent orchestration framework for persistent work on programming and mathematical tasks. It combines specialized agents, iterative evaluation, failure recovery, and budget controls around explicit success criteria. The project reflects my interest in long-horizon autonomy and verifiable feedback.

Topics: Autonomous agents · Verification

SmokeAgent

Language-model agents for scientific simulation

SmokeAgent is a research prototype that translates written smoke-control requirements into structured simulation workflows using NIST's Fire Dynamics Simulator (FDS). Built on Foam-Agent, it separates language-model planning from deterministic input generation, validation, and evaluation. It explores how agents can interact with scientific tools through explicit, checkable steps.

Topics: Scientific agents · Simulation

Fast-Sinkhorn-CUDA

GPU-accelerated optimal transport

A C++/CUDA implementation of the entropically regularized Sinkhorn algorithm, using log-domain computation and warp-level GPU reductions. The project explores numerical stability, GPU memory use, and custom kernels for optimal transport computations.

Topics: Optimal transport · CUDA · Numerical methods

llm-recall

Search and resume AI coding sessions

A Go-based command-line tool for searching and resuming local sessions across Claude Code, Codex, and Gemini CLI. It brings session history into a unified interface for recovering working context across tools.
